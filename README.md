# FORMAX Bridge

Modern landing page developed for FORMAX, focused on presenting technical education and online EJA opportunities and guiding potential students to contact the support team through WhatsApp.

The project combines a responsive user interface, reusable React components, marketing-focused sections, social proof, calls to action, and lead tracking.

## Live Demo

https://formax-bridge.vercel.app

## Overview

FORMAX Bridge is a responsive landing page designed to communicate FORMAX's educational services and convert visitors into potential leads.

The page presents information about:

- Online EJA;
- Technical education;
- Competency-based technical certification;
- Support and customer service;
- Student testimonials and social proof;
- Recognition and credibility information;
- Direct WhatsApp contact.

The interface was designed to provide a clear user journey, from the initial presentation of the service to direct contact through WhatsApp.

## Main Features

### Responsive Landing Page

The application uses a responsive layout designed for desktop and mobile devices.

The page is organized into different sections, including:

- Hero section;
- Credibility and benefits;
- Educational opportunities;
- Transformation and career messaging;
- Social proof;
- Testimonials;
- Calls to action;
- Contact sections.

### WhatsApp Conversion

The application provides multiple WhatsApp call-to-action buttons throughout the page.

When a visitor clicks a WhatsApp button, the application opens a predefined conversation containing information about the visitor's interest.

Different buttons use different source identifiers, allowing the application to distinguish where the interaction originated.

### Lead Tracking

The project includes support for Meta Pixel event tracking.

WhatsApp interactions can be registered as `Lead` events, with the source of the interaction included as event data.

This allows marketing campaigns to measure interactions generated by different sections of the landing page.

### Reusable Components

The interface uses reusable React components for elements such as:

- WhatsApp buttons;
- Cards;
- Icons;
- Content sections;
- Navigation elements;
- Call-to-action components.

This reduces duplication and makes the interface easier to maintain.

### Visual Design

The project includes a custom visual system with:

- Gradients;
- Responsive typography;
- Cards;
- Shadows;
- Rounded components;
- Animations;
- Hover effects;
- Responsive layouts;
- Custom brand styling.
